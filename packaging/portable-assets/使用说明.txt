灵动 Code 绿色包 — 配置如何保留
================================

从本版本起，模型密钥、工作区、会话等默认保存在：

  %APPDATA%\Lingdong

换新包 / 解压覆盖时，只要还是同一台 Windows 用户，配置会自动保留，
不必每次重新填 Key、重新加仓库。

推荐用法
--------
1. 关掉正在运行的灵动 Code
2. 解压新包到任意目录（可覆盖旧目录，也可解压到新文件夹）
3. 双击「启动灵动Code.cmd」（或直接双击 Lingdong.exe）
4. 模型和仓库应还在

从旧版「包内 data」迁配置
------------------------
如果你以前一直用桌面上的 Lingdong\data，第一次用新包时请：

1. 关掉灵动 Code
2. 双击「迁移旧配置.cmd」
3. 按提示把旧 data 拷到 %APPDATA%\Lingdong
4. 再启动

真正的 U 盘便携（可选）
----------------------
若需要「整个文件夹拷走就能用、不写 AppData」：
在 Lingdong.exe 同级手动新建空文件夹，命名为 data，再启动。
之后配置会重新写进这个 data（换包时请自行拷贝 data，否则会丢）。
